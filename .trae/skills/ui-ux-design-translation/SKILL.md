# UI/UX Design Translation

Esta skill é especializada em converter visuais de protótipos (como Figma, imagens ou mockups) em código Blazor (Razor/CSS).

## Diretrizes
- Analisar cores, tipografia, espaçamento e iconografia das imagens.
- Criar componentes modulares que reflitam fielmente o design.
- Utilizar variáveis CSS para manter a consistência do tema.
- Garantir que a fidelidade visual não comprometa a acessibilidade.
