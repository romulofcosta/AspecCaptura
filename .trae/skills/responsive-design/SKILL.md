# Responsive Design

Garante que a aplicação funcione perfeitamente em dispositivos móveis, tablets e desktops, com foco especial na experiência PWA.

## Diretrizes
- Utilizar Mobile-First design.
- Implementar suporte para `safe-area-inset` (especialmente para iOS).
- Usar Flexbox e Grid para layouts flexíveis.
- Otimizar alvos de toque (mínimo 44px) e legibilidade de fontes em telas pequenas.
