# Componentization

Skill dedicada à criação de bibliotecas de componentes internos que facilitam a manutenção e consistência visual.

## Diretrizes
- Identificar padrões repetitivos na interface.
- Criar componentes base (Botões, Inputs, Cards) com parâmetros claros.
- Isolar a lógica de apresentação da lógica de negócio sempre que possível.
- Documentar os parâmetros (`[Parameter]`) e eventos (`EventCallback`) dos componentes.
