v1.5.0 - UI/UX Overhaul: Footer Fix, MudSelect Upgrade and Comprehensive Visual Improvements

## 🎨 Major UI/UX Improvements

### Footer Navigation Fix (CRITICAL)
- Fixed missing footer on Home page due to z-index conflicts
- Increased footer z-index from 1030 to 1050 for proper visibility
- Added global CSS fixes for MudMainContent and drawer overlay
- Adjusted Home container padding-bottom for proper spacing
- Footer now visible and functional across all authenticated pages

### Selection Fields Complete Overhaul
- Replaced native HTML `<select>` elements with MudBlazor MudSelect components
- Removed ~120 lines of complex native select CSS styling
- Added contextual icons to all select fields:
  * Estado: LocationOn icon (📍)
  * Município: LocationCity icon (🏙️)
  * Unidades Gestoras: Business icon (🏢)
- Implemented dynamic placeholders based on field dependencies
- Fixed dropdown alignment with AnchorOrigin and TransformOrigin properties
- Added smooth animations and hover effects to dropdown items

### Visual Polish & Consistency
- Enhanced chips container with gradient background and dashed border
- Improved "Adicionar unidade" button with hover lift effect
- Added error message styling with shake animation and colored background
- Improved MudSelect popover styling and list item interactions
- All components now 100% consistent with MudBlazor design system
